# Movie Night Decision Engine

A cinema-themed movie picker. Choose your languages, moods, genres and platforms, then spin the roulette.

**Live site:** `[https://<your-username>.github.io/movie-night/`](https://aashishcherian.github.io/movie-night/)

## About the data

- 1,200 films: 100 for each of 12 languages.
- Ratings come from IMDb search results captured in November 2026. IMDb data is for personal, non-commercial use.
- The synopses are short editorial summaries.
- **Streaming availability is illustrative demo data.** It is not real availability in India.
- The trailer button opens a YouTube search, not a specific video.

## Files

- `index.html` contains the whole app (HTML, CSS, JavaScript and data) in one file with no external dependencies.
- `.nojekyll` tells GitHub Pages to serve the files as they are.

A Tableau data app version of this app also exists. It runs on Tableau Cloud and reads the same catalogue from Tableau datasources.
